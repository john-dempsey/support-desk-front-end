A Pretend Page

Node has no document or window. jsdom builds them in JavaScript, so React can create real elements in a test, though nothing is ever drawn.

Tests run in Node, not in a browser. Node can run JavaScript, but it has no document, no window and no HTML elements: those come from the browser. React needs them, because rendering a component means creating elements and putting them in the document.

jsdom builds them, in plain JavaScript. With environment: 'jsdom' in vite.config.js, every test file gets a pretend page before it starts (step 1 in topic 01's diagram):

jsdom does jsdom doesn't
document, window, localStorage open a window or draw anything
create elements, set attributes and text work out sizes or positions on screen
fire events (click, input, ...) and run their handlers load CSS layouts, images or fonts

That's enough to test what a component shows and does, which is what the app's tests check. It's not enough to test how it looks: whether the badge is green, or a column fits on a phone. For that you still open a browser.

Try it

Add this line at the very top of src/pages/HomePage.test.jsx, above the imports:

// @vitest-environment node

A comment in this form changes the environment for one file. Run npx vitest run src/pages. All three tests fail with:

ReferenceError: document is not defined

Without jsdom, there's nowhere to put the page. Remove the line.
