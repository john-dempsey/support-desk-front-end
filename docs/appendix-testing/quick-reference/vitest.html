Vitest at a Glance

describe, it, hooks, matchers, stand-ins, fakes and settings: every part of Vitest the app's tests use, with the topic that explains it.

Everything here is imported from 'vitest'. The last column is the topic of this appendix that explains it.

Structure

Function Does Topic
describe(name, fn) runs fn at once to save a group of tests under name 02
it(name, fn) saves a test, to run later; it passes if fn doesn't throw (test is the same) 02
it.only, it.skip run only this test / skip this test 02
beforeEach(fn), afterEach(fn) save fn to run before / after every test 03

Checks: expect(value).matcher(...)

Matcher Passes when the value ... Topic
toBe(x) is x (the same value, or the same object) 02
toEqual(x) has the same contents as x 02
toMatchObject(x) has at least the properties in x 02
toBeNull(), toBeUndefined() is null / undefined 02
toHaveLength(n) has length n (array or string) 06
toContain(x) is an array holding x, or a string containing x 06
toHaveBeenCalled() is a fake that was called at least once 04
toHaveBeenCalledWith(...) is a fake that was called with these arguments, in any call 07
toHaveBeenLastCalledWith(...) ... in its latest call 08
toHaveBeenCalledTimes(n) is a fake called exactly n times 07
.not. turns any matcher round 02
await expect(promise).rejects. waits for promise to fail, then checks the error 02

Stand-ins, inside an expected value

Stand-in Matches Topic
expect.objectContaining({...}) an object with at least these properties 08
expect.stringContaining('...') a string containing this 02

Fakes

Function Does Topic
vi.fn() makes a fake function that records its calls in .mock.calls 04
.mockReturnValue(x), .mockResolvedValue(x), .mockRejectedValue(e) sets the fake's everyday answer 04, 07
.mockImplementation(fn) the fake runs fn, with the same arguments 07
.mockReturnValueOnce(x), .mockResolvedValueOnce(x) adds a one-off answer to the queue 08
vi.mock(path) replaces a module: every function becomes a vi.fn() 04
vi.mock(path, factory) replaces a module with what factory returns 10
vi.hoisted(fn) runs fn at the very top, before the imports 10
vi.spyOn(object, 'method') replaces one method of an existing object 08
vi.stubGlobal(name, value) replaces a global, such as fetch 04
vi.stubEnv(name, value) replaces an import.meta.env value 07

Settings (test in vite.config.js)

Setting Does Topic
environment: 'jsdom' gives every test file a pretend page 01, 05
setupFiles runs setup.js at the start of every test file 03
mockReset, unstubGlobals, unstubEnvs undo every fake before each test 03
coverage which files npm run coverage reports on 11
