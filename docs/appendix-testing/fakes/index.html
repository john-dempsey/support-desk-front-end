Fakes: vi.fn, vi.stubGlobal and vi.mock

Needs Stage 0. A fake function that records its calls and answers as it's told, a global swapped for one, and a whole module replaced by fakes.

  • vi.fn(): a Function That Remembers

    vi.fn() makes a fake function. It records every call, and returns whatever the test tells it to. A homemade one takes ten lines.

  • vi.stubGlobal(): Swapping a Global

    fetch is a global, looked up by name each time it's called. vi.stubGlobal replaces it, so client.js calls the fake without being changed at all.

  • vi.mock(): Replacing a Whole Module

    vi.mock swaps a file for a stand-in whose exported functions are all vi.fn() fakes. Every import of it, the page's included, gets the stand-in, and Vitest moves the call to the top of the file.
