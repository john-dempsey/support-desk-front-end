Changes From Outside React

Needs Stage 5. What act() does and why you rarely see it, the order Vitest runs a file with a mock factory in, and why rerender() is not the same as rendering again.

  • act(): Let React Finish

    A state update doesn't redraw the page straight away. act() runs some code, then makes React finish every redraw and effect it caused. Testing Library already does this for render, clicks and findBy.

  • A Mock Factory, Step by Step

    With a factory, Vitest runs your function to build the fake module, at the moment something first imports it. That happens before the file's own lines, which is why the fake socket needs vi.hoisted().

  • rerender(): the Same Component, Updated

    rerender() draws new JSX in the same place, so React updates the components already there and runs their cleanups. Calling render() again adds a second, separate copy.
