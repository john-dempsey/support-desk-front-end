Hooks, Crashes and Coverage

Needs Stage 6. renderHook() built by hand, what waitFor() needs from its check, two fakes for things that aren't the app's (console.error and DEV), and how a coverage report is counted.

  • renderHook(), by Hand

    A hook can only run inside a component, so renderHook() makes one: a component that calls the hook, saves what it returns in result.current, and draws nothing.

  • What waitFor() Needs From Its Check

    waitFor() runs its check again and again until it stops throwing. A check that returns false instead of throwing counts as passed at once.

  • Faking What Isn't the App's

    ErrorBoundary's tests fake two things the app doesn't own: console.error, to keep the output quiet while still counting calls, and import.meta.env.DEV, to pretend to be the production build.

  • How Coverage Is Counted

    Node's JavaScript engine counts how often each piece of code runs. The coverage report is those counts after the tests finish, mapped back to your source lines.
