What npm test Runs

npm test runs vitest run, which finds every file named *.test.js or *.test.jsx by itself. Two options pick out some of them, and the exit code tells other tools whether everything passed.

npm test runs whatever package.json's "test" script says, and the starter's says vitest run:

Script Runs Does
npm test vitest run runs every test once, prints a summary, and stops
npm run test:watch vitest runs them, then waits, and runs the affected tests again each time you save a file

Finding the tests

Nowhere in the project is there a list of test files. Vitest searches the whole project folder (skipping node_modules) for files whose names match this pattern:

**/*.{test,spec}.?(c|m)[jt]s?(x)

In plain words: any folder, then any name ending in .test or .spec, then .js, .jsx, .ts or .tsx (.cjs/.mjs count too). So HomePage.test.jsx is found because of its name, not because of where it is. That's why test files can sit next to the file they test.

Running only some

Command Runs
npx vitest run src/api only files whose path contains src/api
npx vitest run -t "loading" only tests whose name contains loading

The second one, on the starter, ends:

 Test Files  1 passed | 2 skipped (3)
      Tests  1 passed | 12 skipped (13)

Every file is still read (the next topic explains why it has to be), but only the one matching test runs.

Passing means exit code 0

When every test passes, vitest run ends with exit code 0. When any test fails it ends with 1. You don't see this, but other tools do: a GitHub Action, for example, marks the run as failed when a command exits with anything other than 0.

Try it

  1. Create an empty file, src/scratch.test.js, and run npm test. The run fails: Error: No test suite found in file .... A file whose name matches the pattern must contain at least one test. Delete it.
  2. Run npx vitest run -t "error". How many tests ran, and why those? (Read their names in the test files.)
  3. After a run, type echo $? (Git Bash, macOS or Linux) or echo $LASTEXITCODE (PowerShell) to see the exit code.
