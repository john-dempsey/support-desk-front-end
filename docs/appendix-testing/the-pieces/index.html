The Pieces, and What npm test Does

Needs Stage 0. Five packages, each with one job, and what happens between typing npm test and seeing "13 passed".

  • Five Packages, One Job Each

    Vitest runs the tests, jsdom pretends to be a browser, Testing Library puts components on the page and finds things there, jest-dom adds checks, and user-event clicks and types.

  • What npm test Runs

    npm test runs vitest run, which finds every file named *.test.js or *.test.jsx by itself. Two options pick out some of them, and the exit code tells other tools whether everything passed.

  • A Fresh World for Every File

    Each test file runs in a process of its own, with a new pretend page and its own copy of every module, so nothing one file does can reach another.
