Helpers That Build the World

Needs Stage 4. Stage 4 adds few new tools. Instead, its tests lean on a helper that makes fresh fakes and hands them back, and on jsdom's real localStorage, which a file's tests share.

  • A Helper That Hands Back Its Fakes

    renderWithProviders makes new vi.fn() fakes on every call, puts them where the page will find them, and returns them so the test can program and check them.

  • Real localStorage, Shared by a File's Tests

    jsdom's localStorage really stores things, and it lasts until the file's process ends. So setup.js clears it after every test, or a saved token leaks into the next one.
