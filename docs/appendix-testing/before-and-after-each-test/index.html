Before and After Each Test

Needs Stage 0. Hooks run code around every test. setup.js uses one to clear the page, and two settings in vite.config.js undo every fake, so each test starts clean.

  • Four Hooks

    beforeEach, afterEach, beforeAll and afterAll save a function to run around the tests. They wrap a test like layers: the outermost runs first before it, and last after it.

  • setup.js Runs in Every File

    setupFiles runs setup.js at the start of every test file, so its afterEach wraps every test in the project. It clears the page each test leaves behind.

  • The Settings That Undo Fakes

    mockReset and unstubGlobals are hooks you don't write. Vitest runs them before every test, so a fake from one test is gone before the next one starts.
