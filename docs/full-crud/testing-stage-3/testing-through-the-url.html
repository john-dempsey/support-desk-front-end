Testing Through the URL

The list page's tests start it at a URL and check the query that reaches the API. After a click, they check the last call: the new query.

The ticket list's choices live in the URL (topic 09), so its tests start the page at a URL, and check what reaches the API:

// Figure 3.65: the URL decides the request
// (src/pages/TicketListPage.test.jsx, excerpt)
it('passes the query in the URL to the API', () => {
  getTickets.mockReturnValue(new Promise(() => {}));

  renderWithProviders(<TicketListPage />, {
    route: '/tickets?status=resolved&page=2',
  });

  expect(getTickets).toHaveBeenCalledWith('status=resolved&page=2');
  expect(screen.getByLabelText('Status')).toHaveValue('resolved');
});

(The renderWithProviders(...) call is one line in the file, split here to fit.)

renderWithProviders's route option (Stage 1) puts the whole query in the MemoryRouter's URL. The test checks both directions: the query went to the API, and the dropdown shows it.

After a change: the last call

// Figure 3.66: a new filter, from page 1
// (src/pages/TicketListPage.test.jsx, excerpt)
getTickets.mockResolvedValue(ticketsResult(testTickets, 2, 3));
renderWithProviders(<TicketListPage />, { route: '/tickets?page=2' });
await screen.findByRole('link', { name: 'Cannot log in' });

await userEvent.selectOptions(screen.getByLabelText('Status'), 'Open');

expect(getTickets).toHaveBeenLastCalledWith('status=open');

By the end, getTickets has been called more than once: when the page appeared, and again after the choice. toHaveBeenLastCalledWith checks only the latest call. 'status=open', with no page=2, proves the filter change went back to page 1 (topic 09, slide 04).

ticketsResult() is a small helper at the top of the file that wraps tickets in the { tickets, meta } shape getTickets() now returns.

Pagination on its own

Pagination gets a plain vi.fn() as onPageChange, so its test can click Next and check the page number it was called with, without a router or a ticket in sight. Its tests are the model for any display component that calls a function prop.
