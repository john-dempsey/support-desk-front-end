What Stage 3 Tests

Stage 3's tests do what a user does, typing, choosing and clicking, against the real pages, with fakes for everything outside them.

Stage 2's page tests mostly waited: render the page, let the fake API answer, and check what appeared. Stage 3's pages are about what the user does, so their tests do it too: type into a form, choose from a dropdown, click a button, answer a confirmation box.

The page and its components are the real code. Everything the page talks to is a fake that the test controls:

You've met the first fake (Stage 0) and the router (Stage 1). The other two are new in this stage.

The API module tests

The three new API test files are exactly like Stage 2's tickets.api.test.js: fake apiRequest(), call the function, and check what it was called with. For example, that createComment(2, 'Thanks!') asks for /tickets/2/comments with { body: 'Thanks!' }. They're short, so these slides concentrate on the page tests.

Try it

Open src/api/tags.api.test.js next to tags.api.js, and match each test to the function it tests. Then add one more: check that updateTag() returns the tag the fake apiRequest() sends back, not just that it was called with the right URL.
