Adding a Comment

The page adds the saved comment to its list, and tells the form whether it worked, so the form only empties its box when the comment was saved.

CommentForm works like TicketForm, with one difference. After a new ticket is saved, the page moves on, and the form disappears. After a comment is saved, the user stays on the same page, and the form stays too. Its box should be emptied, ready for the next comment. But only if the comment was saved: if it failed, the user's text mustn't be lost.

So the form needs an answer from the page: did it work?

// Figure 3.39: submitting a comment (src/components/CommentForm.jsx,
// excerpt)
const [commentText, setCommentText] = useState('');
const [isSubmitting, setIsSubmitting] = useState(false);

async function handleSubmit(event) {
  event.preventDefault();
  setIsSubmitting(true);
  const isSaved = await onSubmit(commentText);
  setIsSubmitting(false);

  if (isSaved) {
    setCommentText('');
  }
}

onSubmit is the page's handleAddComment, and it returns true or false:

// Figure 3.40: adding the comment (src/pages/TicketDetailPage.jsx,
// excerpt)
async function handleAddComment(commentText) {
  setCommentError(null);
  try {
    const newComment = await createComment(ticket.id, commentText);
    setComments([...comments, newComment]);
    return true;
  } catch (error) {
    setCommentError(error);
    return false;
  }
}

(The comments are left out.)

  • Saved: createComment() returns the comment as the API saved it, with its id, author and createdAt. The page adds it to the end of its list (the next slide explains [...comments, newComment]), and returns true. The form empties its box.
  • Failed: the page keeps the error, and returns false. The form keeps its text, so the user can fix it and try again.

Errors in the form

The page passes commentError to the form as its error prop, exactly as NewTicketPage did (topic 04). CommentForm shows the message at the top, and uses getFieldError(error, 'body') for the textarea: 'body', because that's the API's name for the field.
