The Comment List

CommentList shows each comment with a Delete button. The button's onClick needs to say which comment, so it wraps the call in an arrow function.

CommentList is a display component, like TicketList: it gets the comments as a prop and shows them.

// Figure 3.37: the comments (src/components/CommentList.jsx, excerpt)
function CommentList({ comments, onDelete }) {
  if (comments.length === 0) {
    return <p>No comments yet.</p>;
  }

  return (
    <ul className="comment-list">
      {comments.map((comment) => (
        <li key={comment.id} className="comment">
          <p className="comment-meta">
            <strong>{comment.author.name}</strong>,{' '}
            {formatDate(comment.createdAt)}
          </p>
          <p className="multiline-text">{comment.body}</p>
          <button
            type="button"
            className="danger-button"
            aria-label={`Delete comment by ${comment.author.name}`}
            onClick={() => onDelete(comment)}
          >
            Delete
          </button>
        </li>

(The end of the file and a comment are left out. The author and date are on one line in the file; {' '} keeps the space between them when they're split, as here.)

Most of it you've seen: the empty state (Stage 2), map() with the comment's id as the key (Stage 1), and formatDate() (Stage 1).

Which comment?

The ticket's Delete button had onClick={handleDeleteTicket}: there's only one ticket, so the function needs nothing more. Here, there's a button per comment, and the page's function needs to know which comment to delete.

onClick={onDelete(comment)} would be wrong: the brackets would call onDelete straight away, during the render, for every comment (topic 03, slide 03). Instead:

onClick={() => onDelete(comment)}

() => onDelete(comment) is a new, small arrow function, made for this one button. It isn't called during the render. When the button is clicked, React calls it, and it calls onDelete with this button's comment.

Many "Delete" buttons

Every comment has a button that says Delete. To a screen reader user moving from button to button, they'd all sound the same. aria-label gives each its own name: "Delete comment by Alex Agent". It starts with the visible word, so someone using voice control can still say "click Delete".

Line breaks

A comment can have several lines. HTML ignores line breaks in text, so the multiline-text class sets white-space: pre-line, which keeps them. The ticket's description uses it too.
