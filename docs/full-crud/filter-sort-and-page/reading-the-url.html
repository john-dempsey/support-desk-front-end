Reading the URL

useSearchParams() gives the page the URL's query string. The dropdowns show what's in it, with the API's defaults when something is missing.

React Router's useSearchParams() is the front-end's req.query: it reads the query string of the current URL.

// Figure 3.51: reading the choices (src/pages/TicketListPage.jsx,
// excerpt)
const [searchParams, setSearchParams] = useSearchParams();
// ...
<TicketFilters
  status={searchParams.get('status') || ''}
  sortBy={searchParams.get('sortBy') || 'createdAt'}
  order={searchParams.get('order') || 'desc'}
  onChange={handleFilterChange}
/>

It returns a pair, like useState():

  • searchParams, a URLSearchParams object (a browser built-in). searchParams.get('status') returns the value as a string, such as 'open', or null if the URL doesn't have it.
  • setSearchParams, which changes the query string, and so the URL (slide 04).

Defaults

On plain /tickets, every get() returns null. The API then uses its own defaults (from listTicketsQuerySchema): every status, newest first. The || makes the dropdowns show the same defaults, so what they say always matches what the list shows:

Missing Shown as Because the API's default is
status All statuses ('') every status
sortBy Date created createdAt
order Descending desc

The dropdowns

TicketFilters is a display component. Each <select> shows the value it's given, and reports a change with onChange(name, value):

// Figure 3.52: the status filter (src/components/TicketFilters.jsx,
// excerpt)
<select
  id="filter-status"
  value={status}
  onChange={(event) => onChange('status', event.target.value)}
>
  <option value="">All statuses</option>
  {TICKET_STATUSES.map((statusValue) => (
    <option key={statusValue} value={statusValue}>
      {STATUS_LABELS[statusValue]}
    </option>
  ))}
</select>

It's a controlled <select> (topic 05), but the value comes from the URL, through props, not from useState. The URL is the state.

The name passed to onChange is the API's parameter name: 'status', 'sortBy' or 'order'. That's what lets the page put it straight into the URL.
