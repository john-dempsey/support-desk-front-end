Pages of Tickets

Pagination shows Previous and Next, and which page this is, from the API's meta. With only 4 seeded tickets, ?pageSize=2 is the way to see it.

The API sends at most pageSize tickets at a time (10, unless asked), and meta says where this page is in the whole list:

{ "page": 1, "pageSize": 2, "total": 4, "totalPages": 2 }

Pagination uses two of those:

// Figure 3.56: Previous and Next (src/components/Pagination.jsx,
// excerpt)
function Pagination({ page, totalPages, onPageChange }) {
  if (totalPages <= 1) {
    return null;
  }

  return (
    <nav aria-label="Pagination" className="pagination">
      <button
        type="button"
        onClick={() => onPageChange(page - 1)}
        disabled={page <= 1}
      >
        Previous
      </button>
      <p>
        Page {page} of {totalPages}
      </p>
      <button
        type="button"
        onClick={() => onPageChange(page + 1)}
        disabled={page >= totalPages}
      >
        Next
      </button>
    </nav>
  );
}

(The comment is left out, and each <button> is on one line in the file, split here to fit.)

  • One page, or none: nothing to move between, so it shows nothing.
  • First page: Previous is disabled. Last page: Next is.
  • Each button calls onPageChange with the page it leads to. On the ticket list, that's handlePageChange (slide 04).

It's a <nav> with its own aria-label, because it's a way of moving around, and a screen reader lists it next to the main navigation as "Pagination".

Pagination doesn't know it's showing tickets. It works for any list that has a page and a totalPages: copy it as it is for your own API.

Seeing it with 4 tickets

The seed has 4 tickets, and a page holds 10, so on plain /tickets there's only one page, and Pagination shows nothing. To see it, ask for smaller pages:

/tickets?pageSize=2

There's no dropdown for pageSize, but the page passes the whole query string to the API (slide 03), so it works anyway. And because handlePageChange keeps everything else in the query, it stays at 2 per page as you click Next.

Try it

  1. Open /tickets?pageSize=2 and click Next. Then choose a different Order. Which page are you on now, and why?
  2. Open /tickets?pageSize=2&page=3. What does the list say? What does Pagination show? Is that sensible? How would you fix it?
