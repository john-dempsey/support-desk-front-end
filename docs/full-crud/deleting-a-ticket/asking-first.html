Delete, Then Go Back →

Asking First

Deleting can't be undone, so handleDeleteTicket asks with window.confirm() first. If the user clicks Cancel, nothing happens.

A deleted ticket is gone: there's no bin to get it back from. One mis-click shouldn't be enough to lose it, so the first thing handleDeleteTicket does is ask:

// Figure 3.32: asking first (src/pages/TicketDetailPage.jsx, excerpt)
async function handleDeleteTicket() {
  const isConfirmed = window.confirm(
    `Delete the ticket "${ticket.subject}"? This can't be undone.`,
  );
  if (!isConfirmed) {
    return;
  }

  // ... the next slide
}

(The comment is left out, and window.confirm(...) is one line in the file, split here to fit.)

window.confirm()

window.confirm() is built into every browser. It shows a small box with a message and two buttons, OK and Cancel, and returns true for OK and false for Cancel.

Until the user answers, the page is frozen: no other code runs, and nothing else on the page can be clicked. That's why it can return the answer straight away, without a promise or await.

The message names the ticket, so the user can check it's the one they meant: "Delete the ticket "Invoice discrepancy"? This can't be undone."

Return early

If the user clicks Cancel, isConfirmed is false, and return ends the function there. No request is sent and no state changes. This early return keeps the rest of the function about the real work, not wrapped inside an if.

Good enough, for now

window.confirm() is quick to write, and browsers make it work with the keyboard and screen readers. But you can't style it, its title shows the page's address, and it looks different in every browser. Most apps build their own dialog instead, which is more work to make accessible. For this stage, the built-in one is the right choice, and building your own is a good challenge for later.

Try it

Change the message so it also includes the ticket's id. Then, in the browser's console, type window.confirm('Sure?') and press Enter. Click each button in turn. What does the console show each time?
