A Link and a Button

A ticket's page gets Edit and Delete under its details. They look alike, but one is a link and one is a button, because one goes somewhere and the other does something.

Under a ticket's details, Stage 3 adds two controls side by side:

// Figure 3.31: Edit and Delete (src/pages/TicketDetailPage.jsx,
// excerpt)
<div className="button-row">
  <Link to={`/tickets/${ticket.id}/edit`} className="button-link">
    Edit ticket
  </Link>
  <button
    type="button"
    className="danger-button"
    onClick={handleDeleteTicket}
  >
    Delete ticket
  </button>
</div>
{deleteErrorMessage && <ErrorMessage message={deleteErrorMessage} />}

(The <button> is on one line in the file, split here to fit.)

Goes somewhere, or does something?

They look alike, but they're different elements, for a reason (topic 03, slide 08):

  • Edit ticket goes somewhere: to the edit page, at its own URL. So it's a <Link>. It can be opened in a new tab, bookmarked, and the Back button returns from it.
  • Delete ticket does something on this page. There's no page to go to. So it's a <button>, with onClick.

A screen reader announces "link" for one and "button" for the other, so users know what to expect before they press it.

onClick

onClick={handleDeleteTicket} is the first click handler in the app. It's the same idea as onChange and onSubmit (topic 03): hand the element a function, without brackets, and React calls it when the button is clicked, or when it has focus and the user presses Enter or Space.

type="button"

A <button> inside a <form> is a submit button unless it says otherwise. This one isn't in a form, so it makes no difference here. But writing type="button" on every button that doesn't submit a form is a good habit: if the button is ever moved into a form, it won't start submitting it by accident.

Red, and the word "Delete"

danger-button makes it white on dark red (10.5:1 contrast), which many apps use for actions that destroy something. But the colour isn't the only signal: the button says "Delete ticket" (Stage 0, topic 07).

Try it

Press Tab until Edit ticket has focus, and press Enter. Go back, Tab to Delete ticket, and press Space. Click Cancel in the box that appears. Then right-click each one: which offers "Open link in new tab"? Why does only one?
