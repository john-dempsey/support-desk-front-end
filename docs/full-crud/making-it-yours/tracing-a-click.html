Tracing a Click

Questions to practise the viva's trace with, now that clicks change data: forms, props that are functions, state in the page, and the URL.

Stage 2's traces started when a page appeared. Stage 3's start with the user doing something: typing, choosing, clicking. The viva's trace is the same shape, component → API module → HTTP request → state update → re-render, with one more step at the front: the event that starts it. Topic 03's diagram, "Following a New Ticket", has a whole one.

Write one yourself

Write the trace for adding a comment, as a numbered list, one line per step, with the file each step is in. Start with the user typing in the comment box, and finish with the new comment on the screen and the box empty. Use topic 03's diagram as a model. You should need about ten steps. Then check it against topic 07, slides 04 and 05.

Questions to practise with

Answer these out loud, with the code open. Then try them again with it closed.

  1. While you type a subject on New ticket, where is the text kept? Which line puts each key there?
  2. Why is it onSubmit={handleCreate} and not onSubmit={handleCreate()}? What would the brackets do?
  3. You click Create ticket. Name every function that runs, in order, until the new ticket's page appears.
  4. The API answers 400 with details. Follow the message from apiRequest() to the red text under Subject. Which attribute makes a screen reader read it?
  5. Why doesn't the edit page show TicketForm until the ticket has loaded? What would go wrong if it did?
  6. The Assigned to dropdown holds a string. Where does the agent's id become a string, and where does it become a number again? What happens to "Unassigned"?
  7. You add a comment. Which component's state changes? How does CommentList find out, when CommentForm can't reach it?
  8. Why setComments([...comments, newComment]), and not push()?
  9. After adding a tag, the page asks the API for the whole list again. After adding a comment, it doesn't. Why the difference?
  10. You choose Open in the status filter. Which function runs, what changes in the URL, what makes the effect run again, and what request is sent?
  11. You choose Open, then quickly Closed. What stops the open tickets arriving last and replacing the closed ones?
  12. With Casey's token, which buttons in this stage would fail? What stops them: the front-end, or the API?

Try it

Pick two questions you couldn't answer with the code closed. Find the answers in the code, then explain each to someone else without looking.
