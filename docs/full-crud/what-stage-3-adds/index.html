What Stage 3 Adds

Three new pages, a link in the navigation, and a map of how they fit together, before any of the code.

  • From Reading to Changing

    Stage 2 could only read tickets. Stage 3 creates, edits and deletes them, and adds comments, tags, and a way to find tickets in a long list.

  • Three New Routes

    Each new page gets a line in App.jsx. One of them, /tickets/new, also fits the pattern /tickets/:ticketId, and React Router still picks the right page.

  • What Changes, and What Doesn't

    Most of Stage 3 is new files. client.js doesn't change at all: the starter already knew how to send a body, read a 204 and keep validation details.

  • Every Control, for Now

    Stage 3 shows every button and form to everyone. Ada's admin token is allowed to use all but one of them, and the API says no to that one.
