Keeping the Whole Error

The page keeps the error object itself, not just its message, because a form needs the details too. The form shows the message at the top.

In Stage 2, the pages kept only the error's message:

setErrorMessage(error.message);

A message was all they showed. A form needs more. For a 400, the useful part isn't the message ("Validation failed"), it's the details: which field, and what's wrong with it. So NewTicketPage keeps the whole error object:

// Figure 3.15: the error, kept whole (src/pages/NewTicketPage.jsx,
// excerpt)
const [saveError, setSaveError] = useState(null);
// ...
} catch (error) {
  setSaveError(error);
}
// ...
<TicketForm ... error={saveError} />

null means "no error". After a failed attempt, saveError is the error apiRequest() threw, with its message, status and, for a 400, details (Stage 0, topic 05). The page passes all of it down to the form, and the form picks out what it needs.

The message, at the top

The first thing in the form is:

// Figure 3.16: the form's error message (src/components/TicketForm.jsx,
// excerpt)
<form className="form" onSubmit={handleSubmit}>
  {error && <ErrorMessage message={error.message} />}

When there's an error, the same ErrorMessage as every other page shows its message, in a role="alert" box that screen readers announce straight away (Stage 0, topic 07). When error is null, && shows nothing.

What the user sees

Every error goes through the same two lines, so the form copes with anything the API (or the network) can say:

What happened status At the top of the form Under a field
Ada's token: not a customer 403 You do not have permission to perform this action nothing
Three spaces as the subject 400 Validation failed subject is required
The token has expired 401 Invalid or expired token nothing
The API isn't running 0 Can't reach the API at ... nothing

The last column is the next slide.

In every case, the inputs keep what the user typed. The error only changes saveError in the page; subject and description are in the form's state, and nothing clears them.
