When the API Says No

The browser checks the basics, but the API has the final say. Its validation details are shown under the field they belong to.

  • Two Sets of Rules

    The browser checks the form before it's sent, using the same rules as the back-end's Zod schema. But only the API's check counts.

  • Keeping the Whole Error

    The page keeps the error object itself, not just its message, because a form needs the details too. The form shows the message at the top.

  • From details to the Field

    getFieldError() looks through the error's details for one field's message. The form asks once for each of its fields.

  • Showing It Under the Field

    FieldError shows the message, and two aria attributes link it to its input, so a screen reader reads it out and the input is marked as having a problem.
