Forms and Buttons in CSS

index.css gains styles for buttons, links that look like buttons, and form fields, with borders strong enough to see.

Until now, the app had no forms and no buttons, so index.css had no styles for them. Stage 3 adds a section for each.

Buttons

/* Figure 3.13: every button (src/index.css, excerpt) */
button,
.button-link {
  display: inline-block;
  padding: 0.5rem 1rem;
  font: inherit;
  color: #ffffff;
  text-decoration: none;
  background-color: var(--colour-link);
  border: 1px solid var(--colour-link);
  border-radius: 0.375rem;
  cursor: pointer;
}

button:disabled {
  opacity: 0.6;
  cursor: not-allowed;
}
  • font: inherit. A browser gives buttons and inputs their own, smaller font. This makes them use the page's.
  • .button-link is a class for a <Link> that should look like a button, such as New ticket. It's still a link, because it goes to another page. A <button> is for doing something on this page. Screen readers announce the two differently, so the right element matters even when they look the same.
  • button:disabled is how the button looks while isSubmitting is true: faded, with a "not allowed" pointer.

White text on --colour-link has a contrast ratio of 7.6:1, well above the 4.5:1 that WCAG AA asks for (Stage 0, topic 07). A disabled button doesn't need to meet it: WCAG makes an exception for controls that can't be used.

Form fields

/* Figure 3.14: form fields (src/index.css, excerpt) */
.form-field {
  display: flex;
  flex-direction: column;
  gap: 0.25rem;
  width: 100%;
}

input,
textarea,
select {
  padding: 0.5rem;
  font: inherit;
  border: 1px solid var(--colour-muted);
  border-radius: 0.375rem;
}

(Two colour lines in the second rule are left out.)

Each .form-field stacks its label above its input (flex-direction: column).

The input border uses --colour-muted, not the paler --colour-border that the tables use. WCAG asks for at least 3:1 between the edge of a control and its background, so people can find the box. --colour-border on white is only 1.4:1; --colour-muted is 6.1:1.

Try it

In the browser's developer tools, select the Subject input and change its border colour to #d1d9e0 (the value of --colour-border) in the Styles panel. Can you still see where the box is? Try it again with your screen's brightness turned down.
