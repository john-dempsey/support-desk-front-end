Creating a Ticket

The first form: controlled inputs, a page that sends the request, a function passed down as a prop, and navigate() to the new ticket.

  • The Page and the Form

    Creating a ticket takes two components: NewTicketPage, which sends the request, and TicketForm, which looks after what's being typed.

  • Controlled Inputs

    Each input shows a piece of state, and typing updates the state. React, not the input, holds the value.

  • A Function as a Prop

    Props can be functions. The page passes handleCreate down as onSubmit, and the form calls it when the user clicks Create ticket.

  • Handling the Submit

    handleSubmit stops the browser's own form handling, gathers the values from state, and disables the button until the page has finished.

  • Going to the New Ticket

    handleCreate sends the ticket, then uses navigate() to go to its page, the front-end's version of a redirect. If it fails, it keeps the error.

  • Following a New Ticket

    Every step from typing in the form to seeing the new ticket, through each file, across to the API and back, including the way back when the API says no.

  • Creating One as Casey

    Only customers can create tickets, so with Ada's token the form shows a 403. Switch to Casey's token to create one, then switch back.

  • Forms and Buttons in CSS

    index.css gains styles for buttons, links that look like buttons, and form fields, with borders strong enough to see.
