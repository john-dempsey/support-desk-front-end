Sending Data, Not Just Asking for It

POST, PATCH and DELETE through the same apiRequest(): what each sends, and what each gives back.

  • POST, with a Body

    createTicket() is getTicket() with two more things: a method, and a body for apiRequest() to send as JSON.

  • PATCH Sends What Changed

    updateTicket() takes the ticket's id and an object of changes. PATCH means the API changes only the fields it's sent.

  • DELETE, and the Empty Answer

    A successful DELETE answers 204 No Content. deleteTicket() has nothing to return, but it can still fail.

  • Three More API Files

    Comments, tags and agents each get their own file in src/api/, with the same shape as tickets.api.js. Each one is shown in the topic that uses it.
