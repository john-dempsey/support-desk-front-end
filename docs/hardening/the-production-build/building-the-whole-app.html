Building the Whole App

Stage 0 built the starter. The finished app still builds to three files, and its index.html now points at them.

Stage 0 ran npm run build on the starter: one page that called GET /welcome. Six stages later the app has ten pages, a socket and a context for the logged-in user. It still builds the same way:

npm run build

✓ 167 modules transformed.
dist/index.html                   0.46 kB │ gzip:   0.30 kB
dist/assets/index-DcoHriLX.css    4.77 kB │ gzip:   1.42 kB
dist/assets/index-CPcL75JA.js   329.09 kB │ gzip: 102.15 kB
✓ built in 212ms

(Your hashes and times will be different.) A module is one file that something imports: our src/ files and every library file they pull in. All 167 of them end up in one JavaScript file and one CSS file. The starter's JavaScript was 260 kB, so the six stages added about 70 kB.

The built index.html

The index.html you edit points at /src/main.jsx, which only the dev server understands. The built one points at the two files the build made:

<!-- Figure 6.36: the built page (dist/index.html, reflowed) -->
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <link rel="icon" type="image/svg+xml" href="/favicon.svg" />
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0" />
    <title>Support Desk</title>
    <script type="module" crossorigin
            src="/assets/index-CPcL75JA.js"></script>
    <link rel="stylesheet" crossorigin
          href="/assets/index-DcoHriLX.css">
  </head>
  <body>
    <div id="root"></div>
  </body>
</html>

Everything else is the same: the empty <div id="root"> that React fills, and the <title> that topic 05's PageTitle goes in front of. The favicon.svg is copied across from public/ unchanged.

Try it

Run npm run build. Open dist/index.html next to the index.html in the project's own folder. Which two lines are new, and which line has gone? Then run npm run build again without changing anything: do the file names change?
