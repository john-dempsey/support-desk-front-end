Preview, and Where It Stops

npm run preview answers every address with index.html and tells the browser never to keep a file. A real web server does neither unless it's told to.

npm run preview is the quickest way to try the build, and Stage 0 used it for that. But it's a tool for checking a build, not a web server for users, and two things it does are worth knowing before you pick a real one.

It answers every address with index.html

/tickets/3 isn't a file in dist/. The preview server sends index.html instead, React Router reads the address, and the ticket's page appears. That's the fallback from Stage 0, and it's why a refresh on a deep address works.

Preview does it for every address it has no file for. Even /assets/missing.js, which is clearly meant to be a file, gets index.html, and React shows "Page not found".

It tells the browser not to keep anything

Every answer from preview, the hashed .js and .css files included, has this header:

Cache-Control: no-cache

That tells the browser to check with the server before using a copy it already has. Fine while you're checking a build, but it hides the reason the file names have hashes in them. Topic 08 shows what a real server can do with those names.

A plain web server has no fallback

Any web server can send the files in dist/. But a plain one only sends files that exist. Python has one built in: serving dist/ with it, / works and so does clicking around (React Router changes the address without asking the server). Reload on /login or /tickets/3, though, and the server looks for a file with that name, finds none, and answers:

Error code: 404
Message: File not found.

So whichever server you use must be told: "if there's no such file, send index.html". That's the one line topic 08 adds to nginx.

Try it

  1. With npm run preview running, open http://localhost:4173/assets/missing.js. Who answers: the server or React?
  2. In the Network tab, reload, click the .js file's row, and find Cache-Control under Response Headers.
  3. If you have Python 3, stop preview and run python3 -m http.server 8765 -d dist (on Windows, python or py instead of python3). Open http://localhost:8765 and click Log in: the login page appears. Now reload. Stop the server with Ctrl+C.
