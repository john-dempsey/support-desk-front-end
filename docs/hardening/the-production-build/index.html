The Production Build

What npm run build makes of the whole app: three files with the API's address written in, mostly React, and none of development's extra checks.

  • Building the Whole App

    Stage 0 built the starter. The finished app still builds to three files, and its index.html now points at them.

  • The API's Address Is Built In

    The build writes VITE_API_URL's value straight into the JavaScript, twice, and drops the fallback it no longer needs.

  • What's in the 329 kB

    Most of the built JavaScript is React. Our own code, every page and component from six stages, is less than a tenth of it.

  • Production Isn't Development

    The built app sends each request once, has no component names, and leaves out everything marked as development only.

  • Preview, and Where It Stops

    npm run preview answers every address with index.html and tells the browser never to keep a file. A real web server does neither unless it's told to.
