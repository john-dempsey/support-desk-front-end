The Same Effect Five Times

Five pages each carry their own copy of the loading pattern from Stage 2. Only the request is different.

Stage 0's HomePage showed the pattern for a page that loads data, and Stage 2 said every page would follow it. By the end of Stage 5, five pages do. Here's the ticket list's copy:

// Figure 6.1: Stage 5's version (src/pages/TicketListPage.jsx, excerpt)
  const [tickets, setTickets] = useState(null);
  const [meta, setMeta] = useState(null);
  const [errorMessage, setErrorMessage] = useState('');
  const [isLoading, setIsLoading] = useState(true);
  // ...

  useEffect(() => {
    let ignore = false;

    async function loadTickets() {
      // ...
    }

    loadTickets();

    return () => {
      ignore = true;
      setTickets(null);
      setMeta(null);
      setErrorMessage('');
      setIsLoading(true);
      setHasChanged(false);
    };
  }, [queryString, reloadCount]);

The comments are left out, and so is the body of loadTickets() (// ...): it's the try, catch and finally from Figure 2.8, now with a query string and setMeta.

Five copies

Page What it loads Its own extras
TicketListPage getTickets(queryString) a cleanup that resets, reloadCount
TicketDetailPage getTicket and getComments, together 404 means "not found", a cleanup that resets, reloadCount
EditTicketPage getTicket and getAgents, together
TagsPage getTags() loads again after a tag is added or renamed
NotificationsPage getNotifications() a push adds one to the top

Why five copies is a problem

  • A fix has to be made five times. If the pattern had a mistake, it would be in five places, and fixing one page wouldn't fix the others.
  • Each page is harder to read. Before you reach what makes the page different, you have to read past 30 lines you've seen before.
  • It's harder to test. The ignore flag is the trickiest part, and no test checks it on its own: it's buried in five pages.

It's the same idea as back-end Lesson 1's "Services as a Layer": each controller says what it wants, and the service knows how. Here, each page will say what to load, and one hook will know how to wait for it.
