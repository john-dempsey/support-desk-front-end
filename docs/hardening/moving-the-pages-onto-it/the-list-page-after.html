The List Page, After

TicketListPage's four pieces of state and its whole effect become one line. The rest of the page hardly changes.

Figure 6.1 showed the ticket list's state and effect in Stage 5. Here's the same part of the page now:

// Figure 6.10: loading the tickets (src/pages/TicketListPage.jsx, excerpt)
function TicketListPage() {
  const [searchParams, setSearchParams] = useSearchParams();
  const { hasRole } = useAuth();
  // The same as in TicketDetailPage: true once a notification arrives.
  const [hasChanged, setHasChanged] = useState(false);

  // e.g. "status=open&page=2", or '' for plain /tickets. useFetch loads
  // again whenever this string changes, so a new filter, order or page in
  // the URL loads the matching tickets.
  const queryString = searchParams.toString();
  // getTickets() answers { tickets, meta }: one page of tickets, and the
  // API's { page, pageSize, total, totalPages } for Pagination.
  const { data: ticketPage, error, isLoading, reload } =
    useFetch(getTickets, queryString);

(The last line is split in two here to fit.) Four useState lines, reloadCount and the whole useEffect have gone. The query string is the hook's argument, so a new filter or page in the URL loads again, just as [queryString] did.

One result, not two

getTickets() answers with an object holding the tickets and the API's meta (Stage 3). The page used to split it into two pieces of state. Now the hook keeps the whole answer as data, which the page calls ticketPage, and the page reads the parts when it shows them:

// Figure 6.11: showing it (src/pages/TicketListPage.jsx, excerpt)
      {isLoading && <Loading message="Loading tickets…" />}
      {error && <ErrorMessage message={error.message} />}
      {ticketPage && <TicketList tickets={ticketPage.tickets} />}
      {ticketPage && (
        <Pagination
          page={ticketPage.meta.page}
          totalPages={ticketPage.meta.totalPages}
          onPageChange={handlePageChange}
        />
      )}

error is now the whole Error, so the page shows error.message.
