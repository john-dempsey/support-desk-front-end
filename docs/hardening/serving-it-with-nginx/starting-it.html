Starting It

One command builds the image and starts nginx on port 8080, next to the API's stack. Logging in, pushes and Reload all work from there.

The front-end's stack runs next to the API's, each started in its own folder. First the API, as in Lesson 6:

# in the back-end's folder
docker compose up -d

Then the front-end, in the app's folder:

docker compose up -d --build

--build builds the image first: both stages, npm ci and npm run build included. The first time, Docker also downloads the node and nginx images, so it's slower than later builds. Then open http://localhost:8080.

The same app, from nginx

Log in and use it as usual. Everything works, because nothing in the app knows where its files came from:

  • Logging in calls POST /auth/login on port 3000, as before. The API allows requests from any origin (Lesson 6's cors()), so a page from port 8080 is allowed too.
  • Pushes arrive: the socket connects to port 3000 from the browser.
  • Reload on a "this has changed" notice fetches the list again.

localStorage belongs to one origin, and localhost:8080 is a different origin from localhost:5173. So you log in separately on each, and logging out of one doesn't log you out of the other.

Looking inside

The container is called support-desk-front-end-web-1. Compose commands in the app's folder find it by its service name, web:

docker compose ps
docker compose exec web ls /usr/share/nginx/html
docker compose exec web ps -o user,args

The second shows what nginx serves: index.html, favicon.svg, assets, and a 50x.html error page that comes with the nginx image. The third shows nginx's processes: one master process run by root, and several worker processes run by nginx.

To stop it, run docker compose down in the app's folder. The API's stack keeps running.

Try it

Start the front-end's stack and log in on port 8080 as Alex. In another tab, open port 5173 (with npm run dev running) and log in as Ada: the two origins keep separate logins, so Alex stays logged in. As Ada, open an unassigned ticket, click Edit ticket, set Assigned to to Alex and save. What appears on Alex's page on 8080, without a reload? Click Reload. Then, as Ada, edit the ticket again and set Assigned to back to Unassigned.
