Every new test can fail

A test that can't fail is worse than none: it says something is checked when it isn't. So each new test was checked by breaking the code it covers and watching it fail. Try five of them.

Try it

Make each change on its own, run npm test, note which test fails, then put it back:

  1. TicketFilters.jsx: onChange('sortBy', …) → onChange('sort', …).
  2. Pagination.jsx: onPageChange(page - 1) → onPageChange(page + 1).
  3. TicketListPage.jsx, in handleFilterChange: newSearchParams.delete(name); → newSearchParams.set(name, value);.
  4. AuthProvider.jsx, in register(): delete saveToken(result.token);.
  5. TagsPage.jsx, in handleDeleteTag's catch: setDeleteErrorMessage(error.message); → console.log(error);.

Each one fails exactly one test, and none of them failed a test before Stage 6. For number 5, npm run lint still finds 0 warnings and 0 errors: only the test notices that the user is never told.
