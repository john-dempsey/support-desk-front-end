What Changes, and What Doesn't

Stage 6 adds a hook, two components and four files for Docker, and changes the pages. Nothing in src/api/ changes at all.

Here's every file Stage 6 touches, leaving out the tests (each topic ends with its own):

Where New Changed
hooks/ useFetch.js README.md
components/ ErrorBoundary.jsx, PageTitle.jsx TicketList.jsx: a caption. ProtectedRoute.jsx: a title
pages/ The five pages that load data move onto useFetch. Every page gets a title
src/ App.jsx: the error boundary and a skip link. index.css: two new classes
the project's top folder Dockerfile, nginx.conf, .dockerignore, compose.yaml package.json, vite.config.js, .gitignore: a coverage report

(NotificationsProvider.jsx changes too, but only one comment.)

package.json gains one package, @vitest/coverage-v8, and it's a dev dependency: a tool for the tests, which never reaches the browser. The app itself gets no new libraries in this stage.

What doesn't change

  • Everything in src/api/. Not one line. The pages still call getTickets(), getTicket() and the rest; only how a page waits for the answer changes.
  • main.jsx, AuthProvider, both contexts and realtime/socket.js.
  • The test helpers in src/test/: renderWithProviders, the test data and the fake socket.

Try it

Once you have the stage-06 code, list every file in src/ that changed since the end of Stage 5:

git diff --stat stage-05 stage-06 -- src

Then check the claim about src/api/:

git diff stage-05 stage-06 -- src/api

It prints nothing at all. Why can the way every page loads its data change without any change to the files that send the requests?
