An Accessibility Pass

How to look for accessibility gaps, why an automated score isn't enough, and the three gaps this stage fills: page titles, a skip link and a table caption.

  • Finding the Gaps

    Three ways to check an app's accessibility: the keyboard, Lighthouse and a screen reader. Together they found three gaps in the Support Desk app.

  • Lighthouse Says 100

    Lighthouse gave the app 100 for accessibility before this topic and after it. Automated checks only see some problems.

  • What Was Already There

    Most of the app's accessibility was built in from Stage 0. A checklist of what's already in place, and where each part came from.

  • A Title for Every Page

    React 19 lets any component render a <title>, and moves it into the page's <head>. A small PageTitle component gives every page its own.

  • A Skip Link

    A link that's the first thing Tab reaches, hidden until it has focus, lets keyboard users jump past the navigation on every page.

  • A Caption for the Table

    A <caption> gives the ticket table a name. It's hidden on screen, where the heading already says it, but not from screen readers.

  • Testing the Pass

    Each fix gets a test: document.title for the titles, the table's name for the caption, and the first link on the page for the skip link.
