A Skip Link

A link that's the first thing Tab reaches, hidden until it has focus, lets keyboard users jump past the navigation on every page.

Logged in as Ada, the header has five things to Tab through before the page's own content: Home, Tickets, Notifications, Tags and Log out. A keyboard user goes through them on every page. A skip link gives them a shortcut:

// Figure 6.26: the skip link (src/App.jsx, excerpt)
      {/* The first thing a keyboard user reaches with Tab, so they can jump
          past the navigation links on every page. It's hidden until it has
          focus (see .skip-link in index.css). */}
      <a href="#main-content" className="skip-link">
        Skip to main content
      </a>
      <NavBar />
      <main id="main-content" className="container">

It's a plain <a>, not a React Router <Link>. #main-content isn't another page: it's the id of <main>, on this page. Following it moves the browser's place in the page to <main>, so the next Tab goes to the first thing inside it.

Hidden until it's needed

A mouse user doesn't need the link, so it waits above the top of the screen and only slides in when it has focus:

/* Figure 6.27: the skip link's styles (src/index.css, excerpt) */
.skip-link {
  position: absolute;
  top: -10rem;
  left: 1rem;
  padding: 0.5rem 1rem;
  background-color: var(--colour-background);
}

.skip-link:focus {
  top: 1rem;
}

It's moved off-screen, not hidden with display: none, because an element that isn't displayed can't have focus. Then Tab would skip the skip link.

It's added in App.jsx, not in each page, so every page has it. It's not in the Stage 0 template, so add it to your own app (the checklist at the end of this lesson reminds you).

Try it

Open the ticket list, reload the page, and press Tab once. "Skip to main content" appears in the top-left corner. Press Enter: what changes in the address? Press Tab again: what has focus? Now reload and count the Tabs it takes to reach the same place without the skip link.
