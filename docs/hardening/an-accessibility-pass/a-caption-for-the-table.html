A Caption for the Table

A <caption> gives the ticket table a name. It's hidden on screen, where the heading already says it, but not from screen readers.

Stage 1 made the ticket table readable cell by cell, with scope="col" on its headings. But the table itself had no name. A screen reader user can list a page's tables, or jump from one to the next, and this one was just "table".

HTML's <caption> names a table, and it goes straight after <table>:

// Figure 6.28: the caption (src/components/TicketList.jsx, excerpt)
      <table>
        {/* A caption names the table, so a screen reader can say "table,
            Tickets" and list it among the page's tables. The <h1> already
            says this on screen, so the caption is visually hidden. */}
        <caption className="visually-hidden">Tickets</caption>
        <thead>

Hidden from the eye, not the ear

On screen, the page's <h1> already says "Tickets" right above the table, so showing a caption too would say it twice. So the caption gets a class that hides it on screen only:

/* Figure 6.29: visually hidden (src/index.css, excerpt) */
.visually-hidden {
  position: absolute;
  width: 1px;
  height: 1px;
  overflow: hidden;
  clip-path: inset(50%);
  white-space: nowrap;
}

It shrinks the caption to a single pixel and clips away even that (clip-path), and position: absolute takes it out of the layout, so nothing moves. But it's still on the page, so a screen reader still reads it. display: none would hide it from screen readers too, which is the opposite of what's wanted.

.visually-hidden is a common pattern, and you'll find it under that name (or sr-only, for "screen reader only") in most CSS frameworks. It's useful anywhere a screen reader needs words that the screen already shows another way.

Try it

Open the ticket list, right-click the table and choose Inspect. In the Elements panel, select the <table> element, then open the Accessibility pane (next to Styles). What does it give as the table's Name? Now find the <caption> in the Elements panel, double-click its class attribute and delete visually-hidden. What appears on the page, and where?
