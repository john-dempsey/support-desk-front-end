A Title for Every Page

React 19 lets any component render a <title>, and moves it into the page's <head>. A small PageTitle component gives every page its own.

The title is what you see in a browser tab, in the history and in a bookmark, and it's how screen reader users tell their tabs and windows apart. Until now it came from index.html, so every page said "Support Desk".

<title> in a component

React 19 has a feature that makes this easy: a component can render a <title> anywhere, and React moves it into the page's <head>. When the component goes away, React takes the title out again. No effect, no library.

The app wraps it in a tiny component:

// Figure 6.24: PageTitle (src/components/PageTitle.jsx, excerpt)
function PageTitle({ title }) {
  // <title> must have exactly one piece of text inside it. Written as
  // <title>{title} · Support Desk</title>, it would have two pieces and
  // the tab would show no title at all, so the text is joined first.
  return <title>{`${title} · Support Desk`}</title>;
}

Every page renders it next to its <h1>, with the same words:

// Figure 6.25: the ticket's title (src/pages/TicketDetailPage.jsx, excerpt)
      <PageTitle title={ticket.subject} />
      <h1>{ticket.subject}</h1>

So the tab says "Cannot log in · Support Desk" on that ticket, "Tickets · Support Desk" on the list, and "Something went wrong · Support Desk" on the error boundary's fallback. Page first, app second, so the part that differs is what's read and seen first.

Why a component for one line

  • The app's name is written once. Your own app changes it in one place.
  • The text has to be one string. {title} · Support Desk would be two pieces of text inside <title>, and React leaves the title empty, with no warning. The template literal (a back-tick string with ${...}) joins them first. Putting that rule in one component means nobody else needs to remember it.

While a page is loading

The loading screens have no <h1> and no title, so the tab shows index.html's plain "Support Desk" until the page appears. React's title goes in before index.html's, and the browser uses the first one it finds.

Try it

Open three different pages, then look at your browser's history (Ctrl+H, or Cmd+Y on a Mac): can you tell them apart? Now break it on purpose: in PageTitle.jsx, change the return line to return <title>{title} · Support Desk</title>; and reload. What does the tab show now? Is there a warning in the console? Put it back.
