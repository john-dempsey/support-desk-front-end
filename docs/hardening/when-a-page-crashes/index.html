When a Page Crashes

A bug that throws while a page renders blanks the whole app. An error boundary, the app's one class, shows 'Something went wrong' instead.

  • A Crash Blanks the App

    Every failure so far was expected and handled in state. A bug that throws while rendering is different: React removes the whole app.

  • The One Class

    React has no hook for catching a crash, so ErrorBoundary is a class component: the only one in the app.

  • Where It Goes

    The boundary wraps the routes, inside main and below NavBar, and a key tied to the path gives every page a fresh start.

  • What It Doesn't Catch

    A boundary only catches errors thrown while rendering. Event handlers and requests still need try/catch, and the details are for developers only.

  • Testing the Boundary

    A component that always throws tests the fallback, a faked environment variable tests the production version, and an App test checks the key.
