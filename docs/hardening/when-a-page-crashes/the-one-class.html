The One Class

React has no hook for catching a crash, so ErrorBoundary is a class component: the only one in the app.

Every component in this course has been a function. ErrorBoundary is the one exception, and React makes it one: there's no hook that can catch an error thrown while rendering. Only a class component can.

The class is short, and if you've written Laravel controllers, you've seen everything in its first line:

// Figure 6.18: the class (src/components/ErrorBoundary.jsx, excerpt)
class ErrorBoundary extends Component {
  // A class keeps its state in one object, this.state, instead of
  // useState. null means nothing has gone wrong.
  state = { error: null };

  // "static" means React calls it on the class itself. What it returns is
  // merged into this.state, the same as calling a setter.
  static getDerivedStateFromError(error) {
    return { error };
  }
  • extends Component: like class TicketController extends Controller, it gets React's behaviour by extending React's class.
  • state = { error: null }: all its state in one object. null means "nothing has gone wrong", the same idea as useState(null).
  • static getDerivedStateFromError(error): React calls this when any component inside the boundary throws while rendering. What it returns, { error }, is merged into the state, and React renders the boundary again. static means the same as in PHP: it belongs to the class, not to one object.

What it shows

// Figure 6.19: render() (src/components/ErrorBoundary.jsx, excerpt)
  render() {
    if (this.state.error === null) {
      // Nothing has gone wrong: show the page as usual. this.props is the
      // class version of a function component's props.
      return this.props.children;
    }

    return (
      <>
        <PageTitle title="Something went wrong" />
        <h1>Something went wrong</h1>
        <ErrorMessage message="Sorry, this page stopped working. …" />
        {/* ... */}
        <p>
          <Link to="/">Go to the home page</Link>
        </p>
      </>
    );
  }

(The message is cut short here with "…": it goes on "Try another page, or reload this one." One line, the details, is left out: it's on a later slide.) A function component returns its JSX; a class puts it in a method called render().

this means the boundary itself, like $this in PHP. It's safe here: React always calls render() on the boundary, and the class has no event handlers, which is where this can go wrong in JavaScript.

When nothing has gone wrong, the boundary shows its children, the page, and adds nothing of its own. You can't tell it's there.
