When the ID Changes →

One Ticket, from the URL

TicketDetailPage reads the ID from the URL as before, then asks the API for that ticket, using the same pattern as the list with one extra piece of state.

In Stage 1, TicketDetailPage read the ID with useParams() and looked for it in the array with find(). The first half stays. The second half becomes a request:

// Figure 2.11: the page's state (src/pages/TicketDetailPage.jsx, excerpt)
function TicketDetailPage() {
  const { ticketId } = useParams();
  const [ticket, setTicket] = useState(null);
  const [errorMessage, setErrorMessage] = useState('');
  const [isNotFound, setIsNotFound] = useState(false);
  const [isLoading, setIsLoading] = useState(true);

The list page had three pieces of state. This page has a fourth, isNotFound, because "there's no such ticket" isn't the same as "something went wrong", and the page shows them differently. Slide 03 shows how it gets set.

The effect

// Figure 2.12: loading the ticket (src/pages/TicketDetailPage.jsx,
// excerpt)
  useEffect(() => {
    let ignore = false;

    async function loadTicket() {
      try {
        const ticketData = await getTicket(ticketId);
        if (!ignore) {
          setTicket(ticketData);
        }
      } catch (error) {
        // ... see slide 03
      } finally {
        if (!ignore) {
          setIsLoading(false);
        }
      }
    }

    loadTicket();

    return () => {
      ignore = true;
      // ... see slide 02
    };
  }, [ticketId]);

(The comments in the file are left out, and the catch and the cleanup function are shortened.)

It's the same pattern again. Two things are new:

  • getTicket(ticketId) passes the ID from the URL to the API module, which puts it in the request's path: /tickets/2. The ID is still the string '2', and that's fine here. In Stage 1, find() compared it with numbers, so it needed Number(). Now it just goes into a URL, which is text anyway, and the API's validation turns it into a number.
  • The dependency array is [ticketId], not []. That's the next slide.
