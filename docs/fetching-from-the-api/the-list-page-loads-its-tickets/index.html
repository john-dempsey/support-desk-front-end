The List Page Loads Its Tickets

TicketListPage swaps its hard-coded array for three pieces of state and one effect, the same pattern as the starter's HomePage.

  • From an Array to State

    The tickets now arrive after the page appears, so they live in state, and an effect fetches them.

  • null Isn't Empty

    Starting with null instead of [] lets the page tell 'not loaded yet' apart from 'loaded, and there are none'.

  • The Empty State Is Real

    Stage 1 wrote an empty state that could never show. With real data, a new customer sees it straight away.

  • When It Fails

    Whatever goes wrong, the page shows the error's message and stops loading, and the list never appears.
