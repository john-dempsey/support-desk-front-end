null Isn't Empty

Starting with null instead of [] lets the page tell 'not loaded yet' apart from 'loaded, and there are none'.

Here's what the page shows:

// Figure 2.9: what the page shows (src/pages/TicketListPage.jsx, excerpt)
  return (
    <>
      <h1>Tickets</h1>
      {isLoading && <Loading message="Loading tickets…" />}
      {errorMessage && <ErrorMessage message={errorMessage} />}
      {tickets && <TicketList tickets={tickets} />}
    </>
  );

It's the same && shape as HomePage (Stage 0, topic 06): the heading always, then each piece only when its condition is true.

Why start with null?

tickets could have started as an empty array, useState([]). It seems tidier: an array of tickets that's empty until they arrive. But look at what TicketList does with an empty array: it says "There are no tickets to show."

So with [], the first render would show "Loading tickets…" and "There are no tickets to show." For a moment, the page would tell the user something false, and then change its mind.

null and [] mean different things, and the page needs both:

tickets is It means The page shows
null not loaded yet (or the request failed) no list at all
[] loaded, and there are none "There are no tickets to show."
[ ... ] loaded the table

{tickets && ...} only shows TicketList once tickets isn't null. An empty array is truthy in JavaScript (only null, undefined, false, 0, '' and NaN are falsy), so [] does reach TicketList, which then shows its empty message.

Each state has one job

  • isLoading decides whether "Loading tickets…" shows.
  • errorMessage decides whether an error shows.
  • tickets decides whether the list shows, and TicketList decides between the table and the empty message.

Try it

The API answers too quickly to see the problem, so slow it down. In the browser's developer tools, open the Network tab and change No throttling to 3G. Reload the Tickets page: "Loading tickets…" stays on screen for a while.

Now change useState(null) to useState([]) for tickets and reload. What do you see while the tickets load? Change it back, and set the throttling back to No throttling.
