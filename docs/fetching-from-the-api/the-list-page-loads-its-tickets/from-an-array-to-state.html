From an Array to State

The tickets now arrive after the page appears, so they live in state, and an effect fetches them.

In Stage 1, sampleTickets existed before the page did, so the page could pass it straight to TicketList (Figure 2.1). Now the tickets arrive after the page first appears, and the page has to re-render when they do. Data that changes while a page is showing belongs in state (Stage 0, topic 06).

So the page starts with the same three pieces of state as the starter's HomePage:

// Figure 2.7: the page's state (src/pages/TicketListPage.jsx, excerpt)
function TicketListPage() {
  // null means "not loaded yet", which is different from [] ("loaded, and
  // there are none"). TicketList is only shown once this isn't null, so it
  // doesn't say "There are no tickets" while they're still on their way.
  const [tickets, setTickets] = useState(null);
  const [errorMessage, setErrorMessage] = useState('');
  const [isLoading, setIsLoading] = useState(true);

The comment about null is the subject of the next slide.

The effect

The request is sent from a useEffect, so it runs once the page is on the screen. Here it is, without the comment above let ignore:

// Figure 2.8: loading the tickets (src/pages/TicketListPage.jsx, excerpt)
  useEffect(() => {
    let ignore = false;

    async function loadTickets() {
      try {
        const ticketsData = await getTickets();
        if (!ignore) {
          setTickets(ticketsData);
        }
      } catch (error) {
        if (!ignore) {
          setErrorMessage(error.message);
        }
      } finally {
        if (!ignore) {
          setIsLoading(false);
        }
      }
    }

    loadTickets();

    return () => {
      ignore = true;
    };
  }, []); // [] = run once, when the page first appears

Spot the difference

Put Figure 2.8 next to HomePage's effect from Stage 0 (topic 06), and only the names have changed:

Stage 0's HomePage Stage 2's TicketListPage
welcome, setWelcome tickets, setTickets
loadWelcome() loadTickets()
getWelcome() getTickets()
welcomeData ticketsData

Everything else, try/catch/finally, the ignore flag, the cleanup function and the [], is the same, for the same reasons. That's why Stage 0 called it a pattern: every page that loads data follows it. Recognising it is half the work of reading a new page.
