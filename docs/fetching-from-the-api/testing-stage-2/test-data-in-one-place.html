Test Data in One Place

The page tests no longer use the app's sample data, so they get tickets of their own, in the API's shape, in one shared file.

In Stage 1, the page tests used sampleTickets.js, the same array the app showed. Stage 1's last "Try it" showed the catch: change a subject in the app's data, and tests fail.

Stage 2 deleted sampleTickets.js, so the tests need tickets of their own. The page tests and App.test.jsx all need the same kind of ticket, so they share one file in src/test/:

// Figure 2.16: tickets for the tests (src/test/testTickets.js, excerpt)
export const ticketAssignedToAlex = {
  id: 1,
  subject: 'Cannot log in',
  description: 'Password reset email never arrives',
  status: 'open',
  customer: { id: 1, name: 'Casey Customer', email: 'casey@example.com' },
  assignedAgent: { id: 3, name: 'Alex Agent', email: 'alex@example.com' },
  createdAt: '2026-10-08T09:15:00.000Z',
  updatedAt: '2026-10-08T09:15:00.000Z',
};

export const unassignedTicket = {
  id: 2,
  subject: 'Invoice discrepancy',
  // ... the same fields, with assignedAgent: null
};

export const testTickets = [ticketAssignedToAlex, unassignedTicket];

Named for what makes them different

Each ticket is named for the case it covers: one with an agent, one without. A test that needs an unassigned ticket asks for unassignedTicket, and anyone reading the test can see why that one was chosen. testTickets puts both in an array, for the list page.

The same shape as the API

These are what the fake API "sends" in the page tests, so they have exactly the fields the real API sends and the pages read. If they had a different shape, a page could pass its tests and still break against the real API.

It's the same rule Stage 1 followed for sampleTickets, for the same reason.

Only for tests

The file lives in src/test/, next to setup.js and renderWithProviders.jsx. Nothing outside a test imports it, so the app never shows these tickets, and changing the app's real data (now in the database) can't break a test.

Try it

Change the subject of ticketAssignedToAlex to Cannot sign in and run npm test. Which tests fail, and in which files? Are any of them about the app's real data? Change it back.
