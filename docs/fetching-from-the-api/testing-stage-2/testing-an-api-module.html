Testing an API Module

tickets.api.js is tested by faking the layer under it, client.js, and checking the URL it asks for and what it returns.

tickets.api.js has two jobs per function: ask apiRequest() for the right path, and return the right part of the answer. Its test checks exactly those two things, and nothing else:

// Figure 2.17: testing getTickets() (src/api/tickets.api.test.js,
// excerpt)
import { getTicket, getTickets } from './tickets.api.js';
import { apiRequest } from './client.js';

vi.mock('./client.js');

describe('tickets.api', () => {
  it('getTickets() calls GET /tickets and returns the tickets',
    async () => {
    const tickets = [{ id: 1, subject: 'Cannot log in' }];
    apiRequest.mockResolvedValue({ data: tickets, meta: { total: 1 } });

    const result = await getTickets();

    expect(apiRequest).toHaveBeenCalledWith('/tickets');
    expect(result).toEqual(tickets);
  });

(The it(...) line is one line in the file. It's split here to fit.)

One layer down

The page tests fake tickets.api.js, the layer under the page. This test fakes client.js, the layer under tickets.api.js. Each file is tested on its own, with whatever it calls replaced by a fake:

Test file Fakes So it checks only
TicketListPage.test.jsx tickets.api.js what the page shows
tickets.api.test.js client.js the path, and unwrapping data
client.test.js fetch HTTP: headers, JSON, errors

vi.mock('./client.js') works the same way as Stage 0's vi.mock('../api/welcome.api.js'). It replaces every function the file exports with a fake that does nothing until a test tells it what to return.

What it proves

  • toHaveBeenCalledWith('/tickets'): the function asked for the right path. A typo such as '/ticket' would fail here, without a back-end running.
  • toEqual(tickets): it returned data, not the whole body. The fake sends a meta too, so returning responseBody by mistake would fail.

The tickets here only have id and subject. This test never shows them on a page, so they don't need every field: it only checks that they come back unchanged.
