One File for Ticket Requests

tickets.api.js gives each ticket endpoint a name, so the pages ask for tickets without knowing a single URL.

  • tickets.api.js

    One file holds every ticket request, with one function per endpoint, just like the starter's welcome.api.js.

  • Just the Data, for Now

    GET /tickets sends the tickets and a meta object. getTickets() returns only the tickets, because nothing uses meta yet.

  • When the Ticket Isn't There

    getTicket() has no error handling of its own. The API's 404 or 400 becomes an error with a status, and it passes straight through to the page.
