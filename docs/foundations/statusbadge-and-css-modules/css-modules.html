CSS Modules

A .module.css file holds styles for one component. Vite renames its classes so they can't clash with any other class in the app.

Until now, every style has been in index.css. Its classes are global: a .badge rule there applies to every element anywhere in the app with class="badge". In a small app that's fine. In a bigger one, two people each write a .badge for different things, and one quietly breaks the other.

StatusBadge keeps its styles in a file of its own:

/* Figure 1.17: the badge's styles (src/components/StatusBadge.module.css,
   excerpt) */
.badge {
  display: inline-block;
  padding: 0.125rem 0.5rem;
  border: 1px solid currentColor;
  border-radius: 1rem;
  font-size: 0.875rem;
  font-weight: 600;
  white-space: nowrap;
}

/* One class per status, named exactly like the API's status values. */

.open {
  color: #0550ae;
  background-color: #ddf4ff;
}

It's ordinary CSS. What's different is the file name: it ends in .module.css, and that tells Vite to treat it as a CSS Module.

What Vite does with it

The component imports the file, and gets back an object:

// Figure 1.18: the import (src/components/StatusBadge.jsx, excerpt)
import styles from './StatusBadge.module.css';

Vite gives every class in the file a new, unique name, made from the class name, a code made from the file's location, and the line number. styles maps the names you wrote to the names Vite made, something like this (your code may differ):

styles.badge   // '_badge_85lrl_6'
styles.open    // '_open_85lrl_18'

Those are the names that end up in the HTML and in the CSS. No other file can produce _badge_85lrl_6, so the badge's styles can only ever apply to the badge, and nobody else's .badge can touch it.

Which kind to use

index.css Name.module.css
Applies to the whole app one component
Good for the page layout, links, tables, colours used everywhere styles that only make sense for that component
Used with className="table-wrapper" className={styles.badge}

Try it

  1. Right-click a badge, choose Inspect, and look at its class in the Elements tab. Which parts of the name do you recognise?
  2. Add .badge { outline: 3px solid red; } to the end of index.css. Does any badge get a red outline? Why not? Remove the rule.
