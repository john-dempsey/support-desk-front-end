StatusBadge and CSS Modules

A small component that turns the API's status values into readable, coloured labels, with styles that belong to it alone.

  • From Code Values to Words

    A lookup object turns the API's status values into the words a person should see, with a fallback for anything unexpected.

  • CSS Modules

    A .module.css file holds styles for one component. Vite renames its classes so they can't clash with any other class in the app.

  • Picking the Classes

    The badge looks up its colour class by the status value, the same way it looks up its label, and combines it with the shared badge class.

  • Not Colour Alone

    The badge's colour helps people scan the list, but its words carry the meaning, and every colour pair passes WCAG AA.
