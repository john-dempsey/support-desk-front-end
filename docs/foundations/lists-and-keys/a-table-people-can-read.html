A Table People Can Read

Tickets are tabular data, so they go in a real table, with column headers a screen reader can announce and a wrapper for narrow screens.

The tickets are shown in an HTML <table>, because they are a table: every ticket has the same fields, and you read across a row to see one ticket, or down a column to compare them. (The comment above the <div> is left out here.)

// Figure 1.14: the headings (src/components/TicketList.jsx, excerpt)
<div className="table-wrapper">
  <table>
    <thead>
      <tr>
        <th scope="col">Subject</th>
        <th scope="col">Status</th>
        <th scope="col">Customer</th>
        <th scope="col">Assigned to</th>
        <th scope="col">Created</th>
      </tr>
    </thead>

Headings a screen reader can use

A sighted user looks up to the top of a column to see what a cell means. A screen reader user can't, so the screen reader does it for them: when it reads a cell, it also reads that cell's column heading, as in "Assigned to: Unassigned".

That only works if the headings are real <th> elements, not <td>s styled in bold. scope="col" says each heading belongs to the column below it (rather than to the row beside it). <thead> and <tbody> separate the heading row from the data rows.

This is the semantic HTML from the starter's accessibility topic, applied to a table: use the element that says what the content is.

Narrow screens

Five columns don't fit on a phone. Without help, the table would make the whole page wider than the screen. The wrapper <div> fixes that:

/* Figure 1.15: scrolling the table (src/index.css, excerpt) */
.table-wrapper {
  overflow-x: auto;
}

overflow-x: auto lets the wrapper scroll sideways when what's inside is too wide. The table scrolls; the page doesn't.

The table's styles live in the global index.css, because every table in the app should look the same. The next topic shows the other kind of style: one that belongs to a single component.

Try it

Open the developer tools and turn on the device toolbar (Ctrl+Shift+M), then pick a phone size. Scroll the table sideways. Now remove className="table-wrapper" from the <div> and look again. What scrolls now? Put the class back.
