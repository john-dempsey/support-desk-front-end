From an Array to Rows

.map() turns an array of tickets into an array of table rows, and React shows an array of JSX by showing each item in turn.

TicketList has one ticket array and needs one table row per ticket. This is how it gets them (the comment and four of the cells are left out here):

// Figure 1.10: one row per ticket (src/components/TicketList.jsx, excerpt)
<tbody>
  {tickets.map((ticket) => (
    <tr key={ticket.id}>
      <td>
        <Link to={`/tickets/${ticket.id}`}>{ticket.subject}</Link>
      </td>
      {/* ... four more cells ... */}
    </tr>
  ))}
</tbody>

What .map() does

.map() is an array method, like find(). It calls your function once for each item, and collects whatever the function returns into a new array, the same length as the old one:

[1, 2, 3].map((number) => number * 2);   // gives [2, 4, 6]

The original array isn't changed. Here, the function turns one ticket into one <tr>, so tickets.map(...) gives an array of four <tr> elements, one for each sample ticket.

React shows arrays

When the value inside { } is an array, React shows every item in it, in order. So the array of <tr>s becomes the rows of the table.

Why not a for loop?

Only an expression can go inside { } in JSX, and a for loop is a statement (the starter explained the difference). .map() is a function call, so it's an expression, and it gives back a value that React can show.

Compared with Blade

It's the same job as @foreach:

@foreach ($tickets as $ticket)
    <tr><td>{{ $ticket->subject }}</td></tr>
@endforeach

Blade repeats a piece of the template for each ticket. React builds an array of rows and shows the array.

Try it

Add an ID column to the table: a <th scope="col">ID</th> at the start of the heading row, and a <td>{ticket.id}</td> at the start of each row. How many places did you have to change to add a cell to every row? Run npm test: do the tests still pass? Then take the column out again.
