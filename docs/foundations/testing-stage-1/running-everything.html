Running Everything

Stage 1 ends with 28 passing tests in eight files, no lint errors and a working build.

Stage 1 has a test for every new piece, next to the file it tests:

Test file Tests Checks
utils/formatDate.test.js 2 a readable date; Unknown date for bad values
components/StatusBadge.test.jsx 2 a known and an unknown status
components/TicketList.test.jsx 4 rows, links, Unassigned, the empty state
pages/TicketListPage.test.jsx 2 the heading and the sample tickets
pages/TicketDetailPage.test.jsx 4 a found ticket, two kinds of missing ticket, the back link
pages/HomePage.test.jsx 2 the welcome heading and the link to the tickets
App.test.jsx 5 each URL shows the right page; the navigation
api/client.test.js 7 unchanged from the starter

Run the checks

npm test
npm run lint
npm run build

A passing test run ends like this:

 Test Files  8 passed (8)
      Tests  28 passed (28)

npm run lint should print no errors, and npm run build should end with a built in line. If all three pass, Stage 1 is done.

What changed in the starter's tests

Stage 1 deleted welcome.api.js, so the tests that faked it changed:

  • HomePage.test.jsx no longer uses vi.mock, because the home page doesn't call the API any more.
  • App.test.jsx no longer mocks welcome.api.js, uses renderWithProviders, and checks the two new routes and the new Tickets link.

client.test.js didn't change at all, because client.js didn't. It's ready for Stage 2.
