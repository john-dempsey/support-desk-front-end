Testing Stage 1

Tests for a plain function, a component with props, components that need a router, and a page that reads the URL, plus the helper they share.

  • Testing a Plain Function

    formatDate has no React in it, so its test just calls it and checks what comes back.

  • Testing a Component With Props

    StatusBadge only uses its props, so its test renders it with different props and checks what a user would read.

  • renderWithProviders

    Anything with a <Link> or useParams() needs a router around it. One shared helper provides it, so no test has to set it up itself.

  • Giving useParams() a Route

    useParams() only knows a parameter when a <Route> with that pattern matched, so the page test passes both the URL and the pattern.

  • Testing a List

    TicketList's tests bring their own tickets, count the rows, look inside one row with within(), and check the empty state.

  • Running Everything

    Stage 1 ends with 28 passing tests in eight files, no lint errors and a working build.
