Same Component, Different Data

Because a component only uses its props, it works with any data it's given: on another page, in a test, or from the API in Stage 2.

A component that only uses its props doesn't mind who gives it those props, or where they got them. Stage 1 already relies on that in three ways.

On another page

The ticket's own page, TicketDetailPage, shows the same badge:

// Figure 1.9: the badge again (src/pages/TicketDetailPage.jsx, excerpt)
<h1>{ticket.subject}</h1>
<p>
  <StatusBadge status={ticket.status} />
</p>

Both pages import StatusBadge from the same file. If the badge's colours or wording ever change, they change in one place, and both pages get the change.

TicketDetailPage is a page, so, like TicketListPage, it gets its own data: it imports sampleTickets and finds the one ticket it needs (topic 06 shows how). The two pages each own their data. The component they share owns nothing.

In a test

TicketList's tests don't use sampleTickets at all. They pass in a small array of their own, made up to include exactly the cases they want to check, such as an unassigned ticket. Topic 07 shows how. TicketList can't tell the difference, because to TicketList it's just a tickets prop.

From the API, in Stage 2

In Stage 2, TicketListPage will get its tickets from GET /tickets instead of the import. That changes how the page gets tickets. The line that hands them over, <TicketList tickets={sampleTickets} /> in Figure 1.6, stays the same apart from the name of the variable passed in. TicketList, StatusBadge and formatDate won't change at all, the same way the back-end's controllers didn't change when Lesson 2 swapped the in-memory array for Prisma.

That's the payoff of the split: the code that gets the data and the code that shows it can each change without the other.

Try it

In TicketListPage.jsx, change the prop to each of these in turn, and save after each one:

<TicketList tickets={sampleTickets.slice(0, 2)} />
<TicketList tickets={[]} />

(slice(0, 2) gives a new array with just the first two items.) What does the table show each time? Which file decided what to show when there are no tickets? Did you have to change TicketList for either one? Put the prop back to sampleTickets when you're done.
