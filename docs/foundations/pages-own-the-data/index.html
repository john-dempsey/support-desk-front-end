Pages Own the Data

A page gets the data and passes it down; a component only displays what it's given. That split is what lets Stage 2 change where the tickets come from without touching how they're shown.

  • A Page and a Component

    TicketListPage gets the tickets; TicketList shows them. One decides what to show, the other decides how it looks.

  • From the Page Down

    The tickets pass down the tree one level at a time, and each component is given only the part it needs.

  • Same Component, Different Data

    Because a component only uses its props, it works with any data it's given: on another page, in a test, or from the API in Stage 2.
