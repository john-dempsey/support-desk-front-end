A Page for Each Ticket

One route that matches every ticket's URL, a hook that reads the ID from it, and a page that finds the ticket and shows it, or says it isn't there.

  • A Route With a Parameter

    /tickets/:ticketId is one route that matches every ticket's URL, the same idea as /tickets/:id in Express.

  • useParams()

    useParams() is a hook that reads the route's parameters from the current URL: the front-end's req.params.

  • URLs Are Text

    The ID from the URL is a string, and the tickets' ids are numbers, so the page converts it before comparing.

  • When There's No Such Ticket

    /tickets/999 matches the route, but there's no ticket 999. The page says so itself, the way the API will answer 404 from Stage 2.

  • A Description List

    The ticket's details are label-and-value pairs, so they go in a <dl>, with a little CSS grid to line them up.
