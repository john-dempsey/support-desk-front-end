useParams()

useParams() is a hook that reads the route's parameters from the current URL: the front-end's req.params.

TicketDetailPage needs to know which ticket the URL asks for. It asks React Router with the useParams() hook:

// Figure 1.26: reading the ID (src/pages/TicketDetailPage.jsx, excerpt)
import { Link, useParams } from 'react-router';

function TicketDetailPage() {
  const { ticketId } = useParams();

useParams() returns an object with one property for each parameter in the matched route's path. For the URL /tickets/2 and the path /tickets/:ticketId, that's:

{ ticketId: '2' }

The destructuring { ticketId } takes the one property out. The name must match the :ticketId in App.jsx exactly. If the page asked for { id } instead, it would get undefined, because the route has no parameter called id.

Another hook

useParams is a hook, like useState and useEffect in the starter: a React function whose name starts with use, called at the top level of a component. It comes from React Router, not React itself, because only the router knows which route matched.

It's also why TicketDetailPage only works inside a router. In the app, main.jsx provides one (<BrowserRouter>). Topic 07 shows what a test has to do instead.
