Formatting Dates

The API sends dates in a format made for computers. One small function, built on the browser's own Intl.DateTimeFormat, turns them into dates people can read.

  • Dates From the API

    JSON has no date type, so the API sends every date as an ISO 8601 string. The front-end decides how a person should see it.

  • Intl.DateTimeFormat

    The browser has date formatting built in. formatDate makes one formatter, set up once, and uses it for every date.

  • When a Date Is Bad

    new Date() doesn't fail on a bad string. It gives an Invalid Date, and formatting that would crash the page, so formatDate checks first.

  • One Function, Many Places

    formatDate is a plain function in src/utils/, used by both ticket pages, the same way the back-end keeps small shared helpers in its utils folder.
