Leaving Once Logged In

If there's a user, LoginPage renders a <Navigate> to the ticket list. One rule covers someone who has just logged in and someone who was already logged in.

// Figure 4.18: leaving the login page (src/pages/LoginPage.jsx, excerpt)
// Once someone is logged in, this page has nothing to do. That includes
// straight after logging in: login() sets the user, this page re-renders,
// and this sends them to the ticket list.
if (user) {
  return <Navigate to="/tickets" replace />;
}

(Indented one step further in the file.)

<Navigate>

<Navigate> is a React Router component. Rendering it changes the URL, straight away, like navigate() from useNavigate() in Stage 3. The difference is when each one is used:

Used Example
navigate('/tickets') in an event handler, after something happens Stage 3: after deleting a ticket
<Navigate to="/tickets" /> while rendering, when the page shouldn't be shown at all here: there's already a user

replace swaps /login for /tickets in the browser's history, instead of adding a new entry. So Back doesn't bring the user back to a login form they no longer need.

One rule, two cases

if (user) is true in two situations, and both should end on the ticket list:

  1. Just logged in. login() set the user, and the page re-rendered.
  2. Already logged in. Someone types /login into the address bar, or clicks a bookmark to it.

The page doesn't need to know which. That's why handleSubmit does nothing after login(): the redirect would happen anyway.

After the hooks

The if (user) comes after every useState call, never before. React needs a component to call the same hooks, in the same order, on every render. A return above a useState would skip it on some renders but not others, and React would stop with an error. Return early only once all the hooks have been called.

Try it

  1. Log in as Alex. Then type /login into the address bar. What happens?
  2. Log out. Starting from the home page, click Log in and log in as Alex. Now press the browser's Back button once. Which page do you land on? Would that be different without replace?
