Protected Pages

ProtectedRoute wraps a page in App.jsx's route table. It sends a visitor to the login page, and tells a user whose role can't use the page, before the page ever loads.

  • Wrapping a Page

    In App.jsx, each page that needs a login is written between <ProtectedRoute> tags. The route table now says who can open each page, as the back-end's route files do.

  • ProtectedRoute, Line by Line

    Three questions, three outcomes: nobody logged in goes to /login, the wrong role sees "Not available", and everyone else gets the page.

  • Not Available

    For the wrong role, ProtectedRoute shows a plain message instead of the page. The page never loads, so it never sends requests that can only fail.
