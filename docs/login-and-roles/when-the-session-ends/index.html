When the Session Ends

A token stops working after a day. When any request gets a 401, client.js tells AuthProvider, and the user is logged out from one place, whatever page they're on.

  • A Token Runs Out

    Tokens last a day. When one runs out mid-session, every request gets a 401. Rather than each page handling that, client.js tells AuthProvider, once, for all of them.

  • Calling It on a 401

    apiRequest() calls the handler when a request that carried a token gets a 401. A wrong password also gets a 401, but carried no token, so it doesn't log anyone out.

  • AuthProvider Logs Them Out

    AuthProvider puts a function in client.js that clears the token and the user. ProtectedRoute does the rest: with no user, every protected page goes to /login.
