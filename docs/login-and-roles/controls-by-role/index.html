Controls by Role

The navigation bar, the ticket list and the ticket page show each user only the links and buttons their role can use. That's for the user's sake: the API still checks every request.

  • The Navigation Bar

    NavBar shows Tickets to anyone logged in, Tags to agents and admins, and the user's name and a Log out button, or Log in and Register for a visitor.

  • Buttons by Role

    The ticket list shows New ticket only to customers. The ticket page shows Edit and Delete only to agents and admins. Each is one hasRole() check around JSX that was already there.

  • Which Comments Can Be Deleted

    The rule for deleting a comment depends on each comment, not just the user's role. The page passes CommentList a function, canDelete(comment), that answers the question for each one.

  • Hiding Is Not Security

    Every check in the front-end can be skipped: the code runs on the user's computer. The API's checks are the ones that keep the data safe. The front-end's make the app easier to use.
