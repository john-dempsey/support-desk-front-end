Lecture Notes

  • The Front-End Starter

    A tour of the starter project every front-end in this module is built on: Vite, React, routing, the API client and the tests.

  • Foundations

    A list of tickets and a page for each ticket, built from components and props, with hard-coded data before any of it comes from the API.

  • Fetching from the API

    The ticket pages stop using a hard-coded array and load real tickets from the Support Desk API, with loading, error and empty states.

  • Full CRUD

    The app stops only reading tickets and starts changing them: create, edit and delete tickets, add and delete comments, manage tags, and filter, sort and page the list.

  • Login and Roles

    Users log in instead of pasting a token into .env. The app knows who they are, shows each role only what it can use, and logs them out when their session ends.

  • Notifications

    Users see what the API has told them: a list of their notifications and an unread count, loaded over REST, then kept up to date live over Socket.IO.
