Telling a Page It Changed

When a notification is about the ticket on screen, the page says so and offers a Reload button, rather than reloading by itself and losing what the user was typing.

  • A Notice With a Button

    RefreshNotice is a message and a Reload button, in a polite live region. The ticket pages show it when the data on screen may be out of date.

  • Is It About This Ticket?

    The detail page listens for notifications, and shows the notice only for one about the ticket it's showing, and not for the customer's own 'ticket created'.

  • Reload Runs the Effect Again

    A reloadCount in the fetch effect's dependency list: adding 1 makes the effect run again. And why the page asks first, rather than reloading by itself.

  • The List, and Who Sees the Notice

    The list page shows a notice for any notification about a ticket. And only people the API tells see a notice at all: a notification isn't a 'something changed' broadcast.
