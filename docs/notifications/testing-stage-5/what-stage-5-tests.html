What Stage 5 Tests

Five new test files and four changed ones. The socket is faked at two different depths, depending on what's being tested.

Every test so far has started with the user, or the page, doing something. Stage 5's new code waits for the server to speak first. A test can't wait for a real server, so it has to play the server's part: it decides when a push "arrives", and what's in it.

How deep the fake goes depends on what's being tested:

  • socket.test.js tests socket.js itself, so it fakes the library underneath it, socket.io-client.
  • The provider and page tests aren't testing socket.js, so they fake the whole module, the same way they fake notifications.api.js.
  • App.test.jsx fakes socket.js too, so the real providers can't try to open a connection.
