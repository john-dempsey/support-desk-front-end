A Connect, a Reconnect, a Push

With the fake socket, a test plays the server: fire('connect') once or twice, or fire a notification, then check what socket.js did.

With fire(), each test can make things happen in whatever order it needs:

// Figure 5.23: the token on every connect
// (src/realtime/socket.test.js, excerpt)
it('connectSocket() connects, and sends the saved token once connected',
  () => {
    saveToken('casey-token');
    connectSocket();

    expect(fakeSocket.connect).toHaveBeenCalled();
    expect(fakeSocket.emit).not.toHaveBeenCalled();

    fakeSocket.fire('connect');

    expect(fakeSocket.emit).toHaveBeenCalledWith(
      'authenticate',
      'casey-token',
    );
    disconnectSocket();
  },
);

it('sends the token again after a reconnect', () => {
  saveToken('casey-token');
  connectSocket();
  fakeSocket.fire('connect');
  // The connection dropped and Socket.IO reconnected by itself.
  fakeSocket.fire('connect');

  expect(fakeSocket.emit).toHaveBeenCalledTimes(2);
  disconnectSocket();
});

(The first test's it( line and its toHaveBeenCalledWith are reflowed to fit.)

Before and after the connect

The first test checks two moments. Just after connectSocket(), emit hasn't been called: the token isn't sent until the server is there to hear it. Only after fire('connect') is authenticate sent, with the token from localStorage. The test saves it there itself with saveToken(), as a login would, and setup.js clears it afterwards (Stage 4).

A reconnect is just another connect

The second test is the reason sendToken is a connect handler (topic 04, slide 03). A reconnection looks exactly like a connection to the code, so firing connect twice is all it takes to test one.

Tidying up

Every test ends with disconnectSocket(). There's one fakeSocket for the whole file, so a sendToken handler left on it would still be there in the next test, and would send the token one extra time. mockReset clears the vi.fn()s between tests, but it can't empty the fake's own handlers list: that's ordinary code.
