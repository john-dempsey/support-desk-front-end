The Socket in DevTools

Watching Socket.IO in the browser's Network tab: the requests that open it, the messages on the WebSocket, and what happens when the connection ends.

  • Five Requests to Open a Socket

    Socket.IO starts with ordinary HTTP requests, then switches to a WebSocket. In Chrome, the token goes in one of the HTTP requests, before the switch.

  • Messages on the WebSocket

    The WebSocket row's Messages list the switch-over, the pings that keep it alive, and each push. A push is followed straight away by the HTTP request that counts again.

  • When the Connection Ends

    Restart the API and the socket reconnects and sends the token again by itself. Log out and it closes. A bad token makes the server close it, and it stays closed.
