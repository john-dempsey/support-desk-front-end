What Stage 5 Adds

Who this stage is for, why it uses two channels (REST and a socket), and which files change, before any of the code.

  • Only If Your API Has Notifications

    Stage 5 needs an API that saves notifications and pushes them over Socket.IO, as well as a login. If yours doesn't, your app is already complete.

  • Two Channels

    Notifications reach the browser two ways: the saved history over REST, and a live push over a socket. Each one on its own would miss something.

  • What Changes, and What Doesn't

    Stage 5 adds a notifications page, a second context, a realtime folder and a notice component. client.js and the other API modules don't change.
