Components Are Functions

A React component is a plain JavaScript function that returns the markup for one piece of the page.

React builds a page out of components. A component is one piece of the page (a navigation bar, an error message, a whole page) and it's written as an ordinary JavaScript function that returns the markup for that piece:

function Greeting() {
  return <h1>Hello, Support Desk</h1>;
}

Yes, that's HTML-like markup in the middle of JavaScript, with no quotes around it. It's called JSX, and it's the subject of the next slide. For now, read it as "this function returns an <h1>".

Once a function like this exists, you use it as if it were a new HTML tag:

<Greeting />

React calls the function and puts whatever it returns on the page at that spot.

A real one

Figure 0.7 is the starter's "page not found" page, a complete component file. (From here on, figures leave out the comment at the top of each file. Open the file itself to read it.)

// Figure 0.7: a component file (src/pages/NotFoundPage.jsx)
import { Link } from 'react-router';

function NotFoundPage() {
  return (
    <>
      <h1>Page not found</h1>
      <p>Sorry, there's no page at this address.</p>
      <p>
        <Link to="/">Go to the home page</Link>
      </p>
    </>
  );
}

export default NotFoundPage;
  • The function returns several lines of markup, so they're wrapped in ( ) to keep return and the markup together.
  • <Link> is a link to another page of the app. For now, read it as <a href="/">. The routing topic explains why it isn't a plain <a>.
  • export default makes the component available to other files, which import it, exactly as in the back-end. There's one component per file, and the file is named after it.
  • The file ends in .jsx to say "this file contains JSX".

Two rules for component names

  • Start with a capital letter: NotFoundPage, not notFoundPage. That's how React tells your components apart from HTML tags: <p> is HTML, <Greeting> is a component. A lowercase <greeting> would be treated as an (unknown) HTML tag, and your function would never run.
  • Name it for what it shows, in PascalCase, like ErrorMessage.

Compared with Blade

A component is closest to a Blade view or partial: a reusable chunk of markup in its own file. The difference is that it's a JavaScript function. That means it can take inputs, make decisions and call other functions in the same language as the rest of your code, with no separate template language to learn.
