Colour, Contrast and the Keyboard

Colours that are easy to read, a focus outline you can see, and never relying on colour alone.

Colours in one place

index.css keeps every colour in a CSS variable (also called a custom property), defined once on :root:

/* Figure 0.24: the colour palette (src/index.css, excerpt) */
:root {
  --colour-text: #1f2328;
  --colour-background: #ffffff;
  --colour-muted: #59636e;
  --colour-border: #d1d9e0;
  --colour-header: #f6f8fa;
  --colour-link: #0550ae;
  --colour-error-text: #82071e;
  --colour-error-background: #ffebe9;
  --colour-focus: #0969da;
}

Everything else uses them, e.g. color: var(--colour-link);. To change a colour across the whole app, you change one line.

Contrast

WCAG AA says normal-sized text needs a contrast ratio of at least 4.5:1 with its background. (1:1 is the same colour twice; 21:1 is black on white.) Every pair the starter uses passes comfortably:

Text Background Ratio
body text white 15.8:1
links white 7.6:1
links navigation bar 7.1:1
loading message (muted) white 6.1:1
error text error background 9.2:1

Light grey text is the usual way apps fail. #aaaaaa on white looks fine to many people, but it's only 2.3:1.

A focus outline you can see

/* Figure 0.25: the keyboard focus outline (src/index.css, excerpt) */
:focus-visible {
  outline: 3px solid var(--colour-focus);
  outline-offset: 2px;
}

Keyboard users press Tab to move from link to link, and the focus outline is the only way they can see where they are. :focus-visible shows the outline when the keyboard moved the focus, but not after a mouse click, so it doesn't bother mouse users. Never remove the outline without putting something as visible in its place.

Never colour alone

About 1 in 12 men and 1 in 200 women have some form of colour blindness. So the starter never shows information only with colour. The current page's link isn't just a different colour: it's bold, with a thicker underline, and it has aria-current="page" (topic 04). The error message has a border and says what went wrong in words.

Try it

  1. Click in the address bar, then press Tab repeatedly. Can you see where you are at every step? Press Enter on a link.
  2. In Chrome's developer tools, open the Lighthouse tab, tick only Accessibility, and run a report on the home page. What score does the starter get?
  3. Change --colour-link to a light blue, #6cb6ff. Then right-click the Home link, choose Inspect, and in the Styles panel click the colour swatch next to color: it shows the contrast ratio. Does it pass? Change it back afterwards.
