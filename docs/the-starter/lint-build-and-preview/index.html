Lint, Build and Preview

Checking the code for mistakes, building the production version, and trying it out before it's deployed.

  • Linting With oxlint

    A tool that reads your code without running it and points out likely mistakes, including breaking the rules of hooks.

  • Building for Production

    npm run build turns the whole app into a few plain files that any web server can host.

  • Previewing the Build

    npm run preview serves dist/ on your own machine, so you can check the real thing before it's deployed.
