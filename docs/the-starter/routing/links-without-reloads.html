Links Without Reloads

Why the app uses <Link> instead of <a>, and what actually happens when you click one.

Topic 03 asked you to read <Link to="/"> as <a href="/"> for now. Here's why it isn't one.

What a plain <a> would do

Suppose NotFoundPage used <a href="/">Go to the home page</a>. Clicking it would make the browser do what it always does with a link:

  1. send a request to the server for /
  2. throw away the current page, including all the JavaScript running in it
  3. load the new HTML, which is the same index.html as before
  4. download and start the whole React app again from the beginning

That's how every link in your Laravel app worked, and it was fine there because the server built each page anyway. Here, it's wasteful: the app was already loaded. Worse, anything the app was holding in memory (data it had loaded from the API, text typed into a form) is lost.

What <Link> does instead

<Link to="/">Go to the home page</Link>

<Link> still puts a real <a href="/"> on the page. So it looks like a link, works with the keyboard, and can still be opened in a new tab with Ctrl+click or the right-click menu. But when it's clicked normally, React Router stops the browser's usual behaviour and does this instead:

  1. changes the URL in the address bar, without loading anything
  2. tells <Routes> the URL has changed
  3. <Routes> shows the component for the new URL

No request, no reload, and the app keeps running. The browser's Back and Forward buttons still work, because React Router records each change in the browser's history.

The rule

  • A link to another page in this app: use <Link> (or <NavLink>, next slide).
  • A link to another website: use a plain <a href="...">. It has to load a different page anyway.

Try it

Open the app, open the developer tools and choose the Network tab.

  1. Go to http://localhost:5173/no-such-page, then click Go to the home page. Does a new request for the page appear in the list? (Look at the Type column for document.)
  2. Now press the browser's refresh button. What appears this time?
  3. In NotFoundPage.jsx, change the <Link to="/"> to <a href="/"> (and </Link> to </a>) and repeat step 1. What's different? Change it back afterwards.
