NavLink and the Active Page

A link that knows when it points at the current page, so the navigation can show the user where they are.

The navigation bar should show which page you're on. NavLink is a Link that does exactly that. Here's the starter's NavBar:

// Figure 0.12: the navigation (src/components/NavBar.jsx, excerpt)
const APP_NAME = 'My App';

function NavBar() {
  return (
    <header className="site-header">
      <p className="app-name">{APP_NAME}</p>
      <nav aria-label="Main">
        <ul className="nav-links">
          <li>
            <NavLink to="/" end>
              Home
            </NavLink>
          </li>
        </ul>
      </nav>
    </header>
  );
}

When a NavLink points at the current page, React Router adds two things to the <a> it creates:

  • class="active", so CSS can style it. The starter makes the current page's link bold, with a thicker underline:

    /* Figure 0.13: the active link (src/index.css, excerpt) */
.nav-links a.active {
  font-weight: 700;
  text-decoration-thickness: 3px;
}

  • aria-current="page", so a screen reader says "current page" when it reads the link. Users who can't see the bold text still find out where they are.

You don't write either of these yourself. NavLink adds and removes them as the URL changes.

What counts as "active"? The end prop

By default, a NavLink is active on its own URL and every URL below it. A link to /bookings would be active on /bookings, and also on /bookings/7. That's usually what you want: while you look at one booking, you're still in the "Bookings" part of the app.

Adding end makes a link active only on exactly its own URL. React Router already treats a link to / that way (otherwise "Home" would be active on every page), so the end on the Home link doesn't change anything. It's there to make the intention obvious to anyone reading the code.

Two more details

  • APP_NAME is a constant at the top of the file, with a TODO (your case study) comment above it. Changing your app's name is one of the first things you'll do.
  • aria-label="Main" gives the <nav> a name, so screen reader users can tell it apart from any other navigation on the page. The accessibility topic covers this.
